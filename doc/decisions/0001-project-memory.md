# 0001：项目记忆与文档分层

- 日期：2026-09-10
- 状态：已采用
- 依据：用户要求初始化项目、构建记忆系统，以及用户提供的项目记忆规范。

## 背景

初始化时工作目录只有 Git 元数据，没有已有代码或文档。需要建立后续工作可读取、可核验和持续更新的上下文。

## 决策

根目录 `AGENTS.md` 承载项目摘要、当前状态、目录索引与长期约定；`doc/TODO.md` 承载当前待办；`doc/Roadmap.md` 承载阶段目标；需求、重要决策和专题知识分别进入 `PRD/`、`decisions/` 与 `note/`。对外使用说明进入根目录 `README.md`。

不采用单一会话流水文件，以避免长期知识与短期状态混杂。`LAST_RUN.md` 已弃用；`CHANGELOG.md` 仅在用户明确要求版本更新时维护。

## 影响

后续任务结束时更新相关主题及待办，不复制整段聊天。项目用途与技术栈尚未确认，因此此次初始化只建立文档骨架。未来确定模块边界后再扩充局部上下文。
